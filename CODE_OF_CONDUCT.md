# Code of conduct

Be direct, be specific, be kind. Criticise work, not people. Assume the person you are
replying to knows something you do not.

Harassment, personal attacks, and discrimination of any kind are not tolerated here, in
issues, pull requests, or anywhere else this project's name is attached. Maintainers will
remove such content and, for repeat offenders, block the account.

To report a problem, email the maintainer listed on the repository profile.
